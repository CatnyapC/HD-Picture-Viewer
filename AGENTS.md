# Repository Guidelines

## Project Structure & Module Organization
- `src/` contains the application code. Entry point is `src/main.cpp` with supporting modules like `src/guiUtils.cpp` and headers in `src/*.h`.
- `src/gfx/` holds graphics assets and converter config (e.g., `global_palette.*`, `convimg.yaml`, and runtime sprites).
- `src/types/` provides custom container types used by the app.
- `bin/` contains built artifacts such as `bin/HDPICV.8xp`.
- Top-level files include `makefile`, `icon.png`, and `ReadMe.md`.

## Build, Test, and Development Commands
- `make` builds the calculator program using the CEdev toolchain (`cedev-config` must be on PATH).
- `make debug` builds a debug variant (see `src/main.cpp` for the expected workflow).
- `make clean` removes build outputs generated by the toolchain.

## Coding Style & Naming Conventions
- Language: C++17; keep compatibility with the TI-84 Plus CE toolchain and libraries (`tice.h`, `graphx.h`, `gfx16.h`).
- Indentation and braces: follow existing files with tab indentation and opening braces on the next line.
- Naming: `camelCase` for functions/variables, `UpperCamel` for types, and `ALL_CAPS` for constants (see `src/globals.h`).
- Headers use `.h`; keep includes ordered by system headers then local headers.

## Testing Guidelines
- No automated test suite is present. Validate changes manually on-device or in an emulator (e.g., CEmu).
- Focus on memory use and key-handling paths, especially in fullscreen rendering and file I/O.

## Commit & Pull Request Guidelines
- Git history shows short, sentence-style messages without strict prefixes; keep commit subjects concise and descriptive (e.g., “Fix 16bpp zoom bounds”).
- PRs should include: a brief change summary, any affected calculator models/OS versions tested, and steps to reproduce or verify.
- For UI or rendering changes, include a screenshot or emulator capture when feasible.

## Configuration & Assets
- Picture conversion is handled externally; reference the converter links in `ReadMe.md` and ensure generated files land in calculator archive memory.
